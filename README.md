# SVUBench

A Comprehensive Benchmark for Proactive Streaming Video Understanding.

[Project website](https://lyxxx1211.github.io/SVUBench/) · [Paper](paper.pdf)

The English project page presents the task taxonomy, dual interaction modes, and Proactive Response Score from the paper, with interactive event, historical matching, and summarization demonstrations.

## Run locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000. The website bundles styles, scripts, and math fonts in `index.html`. Figures use SVG to preserve vector text and lines, with the original figure PDFs linked from the page.
